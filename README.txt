# Noman Khan — Portfolio

A personal portfolio website showcasing my background, technical skills, and projects in computer vision, biometrics, machine learning, and software development.

Built with HTML, CSS, and JavaScript as a static website, with no build step required. Ready to run locally or deploy on Vercel.

## Run Locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.

## Deployment

Deploy the folder on Vercel using the **Other** framework preset, with no build command required.

Update your LinkedIn and GitHub links in `script.js` before deployment.
